# Kit inicial de diseño e instrucciones para Codex

Este ZIP **no contiene todavía la web final ni un backend implementado**. Es una base documental para arrancar el monorepositorio con Codex sin perder las decisiones visuales de Camilo.

## Contenido
- `PORTAFOLIO_PLAN_Y_DISENO.md`: copia del plan original actualizada a v0.2.
- `AGENTS.md`: instrucciones persistentes para Codex, UX, Git y seguridad.
- `docs/DIRECCION_VISUAL.md`: referencia Josh W. Comeau + Linux/KDE, sin clonación.
- `docs/INTERACCIONES_LINUX.md`: encabezados de comandos y franja inferior con hover/focus/click.
- `docs/EVITAR_APARIENCIA_IA.md`: texto original del usuario sobre patrones que no quiere.
- `docs/PALETA_PLASMA.md`: confirmación pendiente del nombre real del tema y sus colores.
- `PROMPT_Codex_PRIMERA_TAREA.md`: primer encargo listo para pegar a Codex.
- `preview/interaccion-linux.html`: prototipo local, autónomo y NO definitivo, únicamente para sentir la interacción Linux.

## Orden sugerido
1. Abrir `preview/interaccion-linux.html` en un navegador para comprobar hover, foco y la franja inferior. Los colores son temporales.
2. Confirmar el esquema de Plasma mediante los comandos de `docs/PALETA_PLASMA.md`.
3. Crear un repositorio GitHub (nombre sugerido `portfolio`) y subir estos documentos. Si ya existe repo, integrarlos sin borrar nada.
4. Entregar `PROMPT_Codex_PRIMERA_TAREA.md` a Codex en ese repositorio.
5. Revisar capturas de la primera rebanada antes de implementar el resto.

No incluye credenciales ni acceso a GitHub. Codex hará push si está conectado al repo y tiene permisos efectivos.
